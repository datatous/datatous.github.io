# 관리자 인라인 편집 모드

DATATOUS 사이트의 텍스트(메인·게시글·About 등)를 **화면에서 바로 클릭해 수정**하고,
로컬 파일에 저장하는 도구. 저장은 로컬에서만 동작하며 라이브 사이트에는 영향이 없다.

## 쓰는 법

터미널 2개를 띄운다.

**① 저장 서버** (원본 파일에 변경을 기록)
```powershell
python tools/admin_edit_server.py
```
→ `admin_serve.bat` 더블클릭으로도 실행 가능.

**② 지킬 프리뷰**
```powershell
bundle exec jekyll serve
```

브라우저에서 `http://localhost:4000` 접속 → **Ctrl+Shift+E** 로 편집 모드 ON.

- 파란 점선이 뜬 텍스트를 클릭해 수정 (Enter=확정, Esc=취소)
- 오른쪽 아래 **변경분 패널**에 수정 내용이 모임 → **저장** 클릭
- 저장되면 원본 `.md`/`.html` 파일이 바뀜 → `git`으로 커밋

## 동작 원리 (안전장치)

- 서버는 **"바뀌기 전 문자열"이 파일에 정확히 1번 등장할 때만** 교체한다.
  못 찾거나(0번) 모호하면(2번 이상) **건너뛰고 패널에 사유 표시** → 파일이 깨질 일 없음.
- HTML→Markdown 변환을 하지 않으므로 `mc-*`, `{% include %}` 등 커스텀 컴포넌트가 그대로 보존된다.
- 그래서 **인라인 서식이 섞인 문단**(`**볼드**`, `<b>...</b>`, `[링크](...)`)은
  자동 저장에서 안전하게 제외된다. 그런 부분은 소스 파일을 직접 고칠 것.
- repo 밖 경로(`../`)·허용 외 확장자는 서버가 거부한다.

## 편집 대상

| 화면 | 원본 파일 |
|------|-----------|
| 메인(홈) 카피 — eyebrow/섹션 제목·리드/CTA | `_layouts/home_landing.html` |
| 게시글 본문 (제목·문단·헤딩·리스트) | `_posts/*.md` |
| About·Profile 등 페이지 | `_pages/*.md` |

> 메인의 "진행 중 프로젝트/최근 글" 카드는 게시글 데이터로 자동 생성되므로 편집 대상이 아니다.
> 그 내용은 해당 게시글에서 고치면 메인에도 반영된다.

## 포트 바꾸기

기본 저장 서버 포트는 4001. 바꾸려면:
```powershell
python tools/admin_edit_server.py --port 4005
```
브라우저 콘솔에서 한 번 지정:
```js
localStorage.setItem('datatous_admin_helper','http://localhost:4005')
```
