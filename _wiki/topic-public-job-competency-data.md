## Summary

직무·역량·직업훈련을 정량 분석할 때 **동의나 IRB 게이트 없이 즉시 확보 가능한 공개 데이터** 목록과, 이 데이터로 수행되는 "AI 직무 노출도" 연구 계열의 포화 상태를 정리한다. 핵심 관찰은 **포화된 연구 영역이라도 분석 대상 데이터를 다른 체계로 옮기면 공백이 생긴다**는 것이다. 영어권 O*NET(직업 단위) 기반 연구는 2026년 현재 포화 상태이나, 한국 NCS(능력단위 단위)를 분석 대상으로 삼은 연구는 확인되지 않는다.

## Key Facts

- **NCS 능력단위 데이터는 로그인 없이 다운로드 가능**하다 — 훈련기준 1,093직종의 능력단위 및 능력단위요소가 공공데이터포털 파일데이터로 공개. [출처: sources/008-research-topic-gating-2026-07-21.md]
- **O*NET Database는 18,796개 task statements / 923개 직업**을 포함하며, 각 과업은 core·supplementary로 구분되고 수행 빈도가 주석된다. [출처: sources/008-research-topic-gating-2026-07-21.md]
- **분석 단위가 다르다** — O*NET은 직업(occupation), NCS는 능력단위/능력단위요소로 **더 미세**하다. 해외 직업 단위 연구 결과를 한국에 그대로 이식할 수 없는 구조적 이유. [출처: sources/008-research-topic-gating-2026-07-21.md]
- **NCS는 직업훈련 과정 편성·자격 설계·교육과정 개발의 실제 기준**으로 쓰이므로, 능력단위 수준 분석은 정책 함의로 직결된다. [출처: sources/008-research-topic-gating-2026-07-21.md]
- **O*NET 기반 AI 노출도 연구는 포화**다 — Frey & Osborne(2017) → Eloundou et al.(2023) → Felten et al. → 2026년에도 arXiv 신규 논문이 계속 나온다. [출처: sources/008-research-topic-gating-2026-07-21.md]
- **국내 NCS × 생성형 AI 연구는 "AI를 도구로 쓴" 연구뿐**이다 — 평가문항 자동생성, 진로교육과정 설계 시스템 등. NCS를 AI 적합도의 **분석 대상**으로 삼은 연구는 검색 범위 내 미발견. [출처: sources/008-research-topic-gating-2026-07-21.md]

## Details

### 공개 데이터 카탈로그 (2026-07-21 확인)

| 데이터 | 내용 | 접근 |
|---|---|---|
| **NCS 능력단위·능력단위요소** | 훈련기준 1,093직종 | 공공데이터포털 파일데이터, **로그인 불요** |
| **NCS 기준정보 API** | 능력단위코드·명·수준, 대/중/소/세분류, 정의 (JSON/XML) | 공공데이터포털 Open API, 무료 |
| **O*NET Database** | 18,796 task statements / 923 occupations | onetcenter.org 공개 다운로드 |
| **HRD-Net 연계정보** | 직업훈련 과정 정보 | 공공데이터포털 Open API, 무료 |
| **국민내일배움카드 훈련과정** | 훈련과정 목록 (K-Digital Training 포함) | 공공데이터포털 Open API, 무료 |

> 전부 공개·무료·즉시 확보 가능하며 **기관 동의나 IRB 게이트가 없다.**
> 개인 연구에서 조직 데이터 접근이 막힐 때의 **표준 대체 경로**가 된다.

### 연구 지형 (2026-07 기준)

| 영역 | 상태 |
|---|---|
| O*NET 기반 AI 노출도 (영문) | 🔴 **포화** — 2026년에도 신규 논문 계속 (AI 에이전트 자동화/증강 잠재력 감사, 업무활동 온톨로지 등) |
| 국내 NCS × 생성형 AI | AI를 **도구로 사용한** 연구만 확인 |
| NCS를 AI 적합도의 **분석 대상**으로 삼은 연구 | 🟢 **검색 범위 내 미발견** |

### 재사용 가능한 패턴 — 포화 영역 우회

> **분석 대상 데이터를 다른 체계로 옮기면 포화 영역을 벗어난다.**

O*NET(직업/영어) → NCS(능력단위/한국어)로 이동하면
① 포화 영역을 벗어나고, ② 분석 단위가 세분화되어 기존 연구의 "직업 단위" 한계까지 동시에 넘는다.
언어·제도·분류체계가 다른 국가 표준 데이터는 이런 우회 경로를 제공하는 경우가 많다.

### 자동화(Automation) vs 증강(Augmentation)

최근 연구는 AI가 업무를 **대체**하는 경우와 **보조**하는 경우를 구분해야 한다고 본다.
적합도를 단일 연속값으로 두지 않고 `자동화형 / 증강형 / 적용 곤란` 구분을 포함해 조작화하는 접근이 유효하다.

### '적합도' 조작화 — 단일 척도는 방어가 어렵다

**하위 차원 평정 → 종합 유형 분류**의 2단 구조가 방어에 유리하다. 하위 차원 예시:

- 산출물의 텍스트·문서 기반성
- 정형성·반복성
- 판단·책임 개입 수준
- 대인 상호작용 필요성
- 물리적 수행 필요성
- 데이터 접근 의존성

### 전문가 라벨링 절차

1. 라벨링 지침서 작성 → **파일럿 20건** 후 지침 수정
2. 라벨러 3~4인이 동일 표본을 **독립 평정**
3. 평정자간 신뢰도: **Krippendorff's α**(순서형), Fleiss' κ 보고
4. 불일치 항목은 합의 회의로 확정하되, **불일치 사유를 별도 기록** — 그 자체가 분석 자료가 된다
